## 2. Ключевые возможности версии v4.7 Pro

### 2.1. Автоматический синхронизатор базы с War Thunder Wiki (`sync_wiki_db.js`)
- Скрипт `scripts/sync_wiki_db.js` напрямую обращается к официальным категориям War Thunder Wiki:
  - **Авиация** (`/aviation?v=l`)
  - **Наземная техника** (`/ground?v=l`)
  - **Вертолёты** (`/helicopters?v=l`)
  - **Большой флот** (`/ships?v=l`)
  - **Малый флот** (`/boats?v=l`)
- **Алгоритм извлечения:** Извлекает встроенный в страницу массив `window.WT_UnitList` и декодирует Gaijin BR по формуле:
  $$\text{BR} = \left\lfloor\frac{\text{index}}{3}\right\rfloor + 1 + \text{fraction}\quad (\text{где index} \pmod 3 \to 0.0, 0.3, 0.7)$$
- **Раздельный БР авиации:** Поддерживает разделение нативного авиационного БР (`rb`) и раздельного танкового БР штурмовки (`trb`).
- **Результаты синхронизации:**
  - База расширена с 3,306 до **3,475 машин** (+169 новых моделей, включая `f_102a_late`, `f_15c_golden_eagle`, `su_30sm2`, `rafale_c_f3` и др.).
  - Обновлены и приведены к актуальному патчу **532 боевых рейтинга** и ранги вплоть до **Ранга IX** и БР до **15.0**.
  - Автоматическая синхронная сборка `global_db.json` и минимизированной версии `global_db.min.json`.

### 2.2. Официальные CDN-спрайты Gaijin и быстрый переход в Wiki
- Интегрированы официальные карточки техники с CDN Gaijin:
  - `https://static.encyclopedia.warthunder.com/slots/{id}.png`
  - Плавная ленивая загрузка (`loading="lazy"`), аккуратный фон и автоматическое скрытие при отсутствии ассета (`@error="$event.target.style.display='none'"`).
- Прямые ссылки на статьи техники в War Thunder Wiki:
  - `https://wiki.warthunder.ru/unit/{id}`
- Визуально оснащены все ключевые разделы сайта:
  1. **Соло-конструктор Авиа РБ:** крупная карточка 16x32, роль самолета, ссылка на Wiki, бейдж готовности.
  2. **Соло-конструктор Танки РБ:** карточки 10x20 для слотов Танк #1, Танк #2, ЗСУ/ПВО и Авиация ТРБ.
  3. **Сводная таблица СРБ / Мульти:** миниатюры техники в первой колонке, ссылка на статью, бейдж ранга (`Ранг VI`).
  4. **Турнирный раздел TSS:** карточки машин с кликабельным переходом на Wiki и бейджами рангов.

### 2.3. Режим «Сквад» (Рандом под БР): Соло и Отряд (2-4 игрока)
- **Летка РБ (Авиация):**
  - По правилам War Thunder в Авиа РБ возрождений нет — берется ровно **1 самолет**.
  - В Соло-режиме подбирается лучший истребитель/ударник в вилке БР $[BR - 0.7, BR]$ с возможностью быстрой замены в 1 клик.
  - В режиме отряда отображается вариативность (Истребители, Штурмовики, Бомбардировщики) для каждого пилота звена.
- **Танки РБ (Смешанный сетап):**
  - Подбор полного сетапа из 4 машин: 2 танка + 1 ЗСУ/ПВО + 1 самолет поддержки (с учетом раздельного ТРБ БР).
  - В отряде для каждого участника выводится боевой сетап из 3 машин (`🛡️ Т1`, `🛡️ Т2`, `🎯 ЗСУ`) + авиация поддержки при фокусе «Все».
- **Интерактивный автокомплит напарников:**
  - Быстрый ввод никнейма с подсказками из `players_list.json` без громоздких `select`-списков.
  - Легкое удаление и замена участников отряда.

### 2.4. Режим Полковых боев (СРБ)
- Учет 1 жизни на бой.
- Для **танкистов** формируется пул вариативности из 1-3 машин в рамках лучшей нации под выбранный недельный брекет БР (ОБТ, городской танк, резерв для позднего спавна).
- Для **авиации** и **ЗСУ** — ровно 1 целевая машина.

## 3. Структура файлов проекта

| Файл / Папка | Назначение |
|---|---|
| `wt-squadron/index.html` | Одностраничный интерфейс Vue 3 + Tailwind v4 с режимами Сквад, СРБ, Мульти и Турниры TSS |

## 4. Команда запуска авто-синхронизации базы

В любой момент при выходе нового патча War Thunder базу техники можно обновить одной командой:

```bash
cd wt-squadron
node scripts/sync_wiki_db.js
```

Скрипт автоматически скачает списки авиации, наземки, вертолетов и флота с `wiki.warthunder.ru`, обогатит базу недостающими машинами, актуализирует БР и ранги, и сгенерирует свежие `global_db.json` и `global_db.min.json`.
